# 📑 저평가 우량주 스크리너 — 초보자 가이드

> **국내(코스피·코스닥) + 미국(나스닥·뉴욕·아멕스) 참고용** | 재무제표 기반 | 한국투자증권(KIS) API
> ⚠️ 이 프로그램은 **매매를 하지 않습니다.** 종목을 조회하고 점수만 매깁니다.

---

## 📌 이 프로그램이 뭔가요?

예전에는 이 프로젝트가 **자동으로 주식을 사고파는 프로그램**이었습니다.
지금은 매매 기능을 전부 없애고, **재무제표를 기준으로 "좋은 회사인데 주가는
싼" 종목을 찾아서 보여주는 참고용 도구**로 바뀌었습니다.

```
KIS 랭킹 API 로 시가총액/거래대금 상위 유니버스 실시간 수집
  (국내: KOSPI+KOSDAQ 가격대별 조회 / 미국: 나스닥·뉴욕·아멕스 가격대별 조회)
     ↓
종목마다 재무 데이터 조회
  국내: 대차대조표 · 손익계산서 · 재무비율 · 수익성비율 · 성장성비율 · 애널리스트 목표가
  미국: PER · PBR · EPS · BPS (KIS 해외주식 API, ROE 는 EPS/BPS 로 근사)
     ↓
"저평가"(PER·PBR·PEG) + "우량"(ROE·마진·부채비율·유동비율)
+ (국내만) "성장" + "애널리스트 의견" 점수 계산
     ↓
하드필터 통과 종목을 딥밸류 / 밸런스 / GARP 세 가지 가중치로 각각 순위 매김
+ 필터와 무관하게 "성장주 TOP" 별도 표 (전분기 대비 매출·이익 증가율 기준)
     ↓
콘솔 표 + JSON 리포트 파일로 저장 (매매는 하지 않음)
```

## 🌍 "전체 종목"의 실제 범위

- **국내**: KIS의 "시가총액 상위" 랭킹 API는 한 번에 최대 30건만 주고 다음 페이지
  조회를 지원하지 않습니다. 그래서 가격대(0~5천원, 5천~1만원, … )를 나눠 KOSPI·KOSDAQ
  각각 여러 번 호출해 중복 제거하는 방식으로 **보통 300~500종목** 규모의 유니버스를
  만듭니다. 코스피·코스닥 전체 2,500여 종목을 전부 포함하는 건 아니고, 거래가
  거의 없는 초소형주는 빠질 수 있습니다.
- **미국**: 처음엔 "시가총액순위" API(거래소당 최대 100건, 페이지네이션 불가)만
  써서 거래소당 100개, 최대 300종목으로 제한됐습니다. 이후 가격대 필터(PRC1/PRC2)를
  지원하는 "거래대금순위" API를 가격대별로 나눠 추가 호출하는 방식으로 확장해서,
  **나스닥 단독으로만 약 550종목, 3개 거래소 합치면 1,000종목 이상**을 봅니다.
  (거래대금 기준으로 잡기 때문에 실제로 활발히 거래되는 종목 위주이며, ETF·레버리지
  상품도 섞여 들어오지만 개별 기업 재무데이터가 없어 ROE 필터에서 자동 제외됩니다.)
- (참고: `pykrx`로 국내 진짜 전체 종목 리스트를 시도했으나 이 환경에서 KRX 데이터
  서버 응답이 깨져서 대신 KIS API 랭킹 방식을 사용했습니다.)

## 🧮 점수는 어떻게 계산되나요?

### 국내 주식

**하드 필터** (하나라도 실패하면 후보에서 제외 -- PEG·마진·유동비율·애널리스트
의견은 데이터 신뢰도가 낮아 하드 필터에는 넣지 않고 점수에만 반영합니다):

| 항목 | 기준 (config.py 에서 조정 가능) | 의미 |
|---|---|---|
| PER | 15배 이하 | 이익 대비 주가가 너무 비싸지 않음 |
| PBR | 1.5배 이하 | 자산 대비 주가가 너무 비싸지 않음 |
| ROE | 8% 이상 | 자기자본으로 충분히 돈을 벌고 있음 |
| 부채비율 | 150% 이하 | 빚 부담이 과하지 않음 |
| 매출액 증가율 | 0% 이상 | 최소한 매출이 줄고 있지는 않음 |
| 당기순이익 | 흑자 | 최근 분기 적자가 아님 |

**점수 구성요소** (4개 원재료 점수, 0~100점):

| 구성점수 | 반영 지표 |
|---|---|
| 저평가(value) | PER, PBR, **PEG**(PER÷영업이익증가율 근사) |
| 우량(quality) | ROE, 부채비율, **순이익률**, **유동비율**(유동자산÷유동부채) |
| 성장(growth) | 매출액 증가율 |
| 애널리스트(analyst) | 증권사 **목표주가 괴리율** (커버리지 없으면 중립 50점) |

이 4개를 **딥밸류 / 밸런스 / GARP** 세 가지 비중으로 각각 합산해서 같은 하드필터
통과 종목을 세 가지 순위표로 동시에 보여줍니다 (스캔은 한 번만 하고 재사용):

| 프로필 | 저평가 | 우량 | 성장 | 애널리스트 | 특징 |
|---|---|---|---|---|---|
| deep_value (딥밸류) | 50% | 35% | 10% | 5% | "일단 싸야 한다" |
| balanced (밸런스) | 35% | 35% | 20% | 10% | 저평가·우량 동률 |
| garp (GARP) | 25% | 25% | 40% | 10% | "적정 가격의 성장주" |

추가로 **"성장주 TOP"** 표는 위 하드필터·가중치와 무관하게, 전분기 대비 매출액
증가율이 `config.SCREENER.GROWTH_MIN`(기본 15%) 이상인 종목만 성장률 순으로
따로 보여줍니다 (PER/PBR 이 비싸도 포함될 수 있음).

### 미국 주식 (데이터 제약으로 국내보다 단순화)

KIS는 해외 종목의 대차대조표·손익계산서·부채비율·성장률·수익성비율을 제공하지
않습니다. 그래서 PER/PBR/ROE(근사치)만으로 평가합니다.
**ROE 근사치 = EPS ÷ BPS × 100** (수학적으로 당기순이익÷자기자본과 동일한
비율이지만, 데이터 기준 시점이 정확히 맞지 않을 수 있어 "근사치"로 취급합니다.)

```
종합점수 = 저평가점수 × 0.5  +  우량점수(근사 ROE) × 0.5
```

> 데이터를 못 가져온 지표는 "모른다"로 보고 하드필터는 관대하게 통과시키되,
> 점수는 중립(50점)으로 처리합니다. 결과의 `reasons` 항목을 항상 같이 확인하세요.

## ⚙️ 처음 시작하는 방법

### 1. 패키지 설치
```bash
pip install -r requirements.txt
```

### 2. API 키 설정
한국투자증권 홈페이지에서 **Open API** 키 발급 후 `.env` 파일에 입력:
```bash
APP_KEY=여기에_앱키_입력
APP_SECRET=여기에_시크릿_입력
CANO=계좌번호8자리
ACNT_PRDT_CD=01
```
> 조회 전용이라도 KIS API 는 로그인(토큰 발급)이 필요해서 계좌 연동은 그대로 필요합니다.
> 매수/매도 권한은 쓰지 않으니 안심하세요 — 이 프로그램에는 주문 코드가 아예 없습니다.
> 해외주식 조회 권한도 계좌에 별도 신청이 필요할 수 있습니다 (KIS 홈페이지에서 확인).

### 3. 실행
```bash
python main.py                # 국내 시가총액 상위 유니버스(약 300~500종목) 스캔
python main.py --market us    # 미국(나스닥·뉴욕·아멕스, 약 1,000종목 이상) 스캔
python main.py --market all   # 국내 + 미국 모두 스캔
python main.py --quick        # 예전처럼 고정 66종목만 빠르게 스캔 (테스트용)
python main.py --top 10       # 상위 10개만 출력
python main.py --show-all     # 필터 통과 종목 전부 출력

python view_report.py          # 가장 최근 리포트를 다시 표로 보기 (API 호출 없음, 즉시 출력)
python view_report.py --list   # 저장된 리포트 파일 목록 보기
python view_report.py --file reports/screening_20260707_125957.json   # 특정 리포트 지정
```

> ⏱️ 전체 유니버스 스캔은 종목 수가 많아 국내는 종목당 API 호출이 7회라 10~20분,
> 미국은 종목당 1회라 1,000종목 기준 10~15분 정도 걸릴 수 있습니다.
> 빠르게 테스트하려면 `--quick` 을 사용하세요.

### 4. 종목 목록 바꾸기 (--quick 모드)
`config.py` 의 `LARGE_CAP_SYMBOLS` / `LOW_PRICE_SYMBOLS` / `SECTOR_SYMBOLS` 에
종목 코드를 추가/삭제하면 `--quick` 실행부터 반영됩니다. 기본(전체 유니버스)
실행은 `full_universe.py` 의 가격대 구간(`KR_PRICE_BANDS`, `US_PRICE_BANDS`)이나
미국 거래소 목록(`US_EXCHANGES`)을 수정해서 범위를 조정합니다.

### 5. 기준값·가중치 조정하기
`config.py` 의 `SCREENER` 클래스 숫자를 바꾸면 "얼마나 엄격하게 걸러낼지"
바로 조정됩니다. 예: `PER_MAX = 10.0` 으로 낮추면 더 저평가된 종목만 남습니다.
`WEIGHT_PROFILES` 딕셔너리를 수정하면 딥밸류/밸런스/GARP 각 프로필의 비중을
바꾸거나 새 프로필을 추가할 수 있습니다 (국내에만 적용, 미국은 단일 점수).

## ⚠️ 주의사항

1. **이 프로그램은 투자 조언이 아닙니다** — 점수가 높다고 반드시 좋은 투자처는 아닙니다.
2. **재무제표는 과거 데이터입니다** — 분기 재무제표는 발표 시점 기준이라 현재 상황과 다를 수 있습니다.
3. **미국 주식은 데이터가 더 제한적입니다** — 부채비율·성장률·마진 데이터가 없고, ROE 는 근사치입니다.
4. **PEG·목표주가 괴리율은 근사/참고용입니다** — PEG 는 EPS 증가율 대신 영업이익증가율로 근사했고,
   애널리스트 커버리지가 없는 종목도 많습니다.
5. **전체 유니버스 스캔은 시간이 걸립니다** — 국내는 종목당 API 7회 호출이라 종목 수에 비례해 오래 걸리고,
   미국도 유니버스가 1,000종목 이상으로 커져서 10분 이상 걸릴 수 있습니다.
6. **API 키 보안** — `.env` 파일을 절대 공유하지 마세요.
7. **매매 기능 없음** — 이 프로그램으로는 주식을 사고팔 수 없습니다. 실제 매매는 증권사 앱/HTS 를 이용하세요.
