# 📑 저평가 우량주 스크리너 — 초보자 가이드

> **국내(코스피·코스닥) + 미국(나스닥·뉴욕·아멕스) 참고용** | 재무제표 기반 | 한국투자증권(KIS) API
> ⚠️ 이 프로그램은 **매매를 하지 않습니다.** 종목을 조회하고 점수만 매깁니다.

---

## 📌 이 프로그램이 뭔가요?

예전에는 이 프로젝트가 **자동으로 주식을 사고파는 프로그램**이었습니다.
지금은 매매 기능을 전부 없애고, **재무제표를 기준으로 "좋은 회사인데 주가는
싼" 종목을 찾아서 보여주는 참고용 도구**로 바뀌었습니다.

```
KIS 랭킹 API 로 시가총액 상위 유니버스 실시간 수집
  (국내: KOSPI+KOSDAQ 가격대별 조회 / 미국: 나스닥·뉴욕·아멕스 상위 100개씩)
     ↓
종목마다 재무 데이터 조회
  국내: 대차대조표 · 손익계산서 · 재무비율 · 수익성비율 · 성장성비율
  미국: PER · PBR · EPS · BPS (KIS 해외주식 API, ROE 는 EPS/BPS 로 근사)
     ↓
"저평가" 점수 + "우량" 점수 + (국내만) "성장" 점수 계산
     ↓
필터를 통과한 종목만 점수 순으로 정렬해서 출력
     ↓
콘솔 표 + JSON 리포트 파일로 저장 (매매는 하지 않음)
```

## 🌍 "전체 종목"의 실제 범위

- **국내**: KIS의 "시가총액 상위" 랭킹 API는 한 번에 최대 30건만 주고 다음 페이지
  조회를 지원하지 않습니다. 그래서 가격대(0~5천원, 5천~1만원, … )를 나눠 KOSPI·KOSDAQ
  각각 여러 번 호출해 중복 제거하는 방식으로 **보통 300~500종목** 규모의 유니버스를
  만듭니다. 코스피·코스닥 전체 2,500여 종목을 전부 포함하는 건 아니고, 거래가
  거의 없는 초소형주는 빠질 수 있습니다.
- **미국**: KIS의 "해외주식 시가총액순위" API는 한 번에 최대 100건을 주므로
  나스닥·뉴욕·아멕스 **거래소별 시가총액 상위 100개씩, 총 최대 300종목**을 봅니다.
- (참고: `pykrx`로 진짜 전체 종목 리스트를 시도했으나 이 환경에서 KRX 데이터
  서버 응답이 깨져서 대신 KIS API 랭킹 방식을 사용했습니다.)

## 🧮 점수는 어떻게 계산되나요?

### 국내 주식

**하드 필터** (하나라도 실패하면 후보에서 제외):

| 항목 | 기준 (config.py 에서 조정 가능) | 의미 |
|---|---|---|
| PER | 15배 이하 | 이익 대비 주가가 너무 비싸지 않음 |
| PBR | 1.5배 이하 | 자산 대비 주가가 너무 비싸지 않음 |
| ROE | 8% 이상 | 자기자본으로 충분히 돈을 벌고 있음 |
| 부채비율 | 150% 이하 | 빚 부담이 과하지 않음 |
| 매출액 증가율 | 0% 이상 | 최소한 매출이 줄고 있지는 않음 |
| 당기순이익 | 흑자 | 최근 분기 적자가 아님 |

```
종합점수 = 저평가점수 × 0.4  +  우량점수 × 0.4  +  성장점수 × 0.2
```

### 미국 주식 (데이터 제약으로 국내보다 단순화)

KIS는 해외 종목의 대차대조표·손익계산서·부채비율·성장률을 제공하지 않습니다.
그래서 PER/PBR/ROE(근사치)만으로 평가합니다. **ROE 근사치 = EPS ÷ BPS × 100**
(수학적으로 당기순이익÷자기자본과 동일한 비율이지만, 데이터 기준 시점이
정확히 맞지 않을 수 있어 "근사치"로 취급합니다.)

```
종합점수 = 저평가점수 × 0.5  +  우량점수(근사 ROE) × 0.5
```

> 데이터를 못 가져온 지표는 "모른다"로 보고 하드필터는 관대하게 통과시키되,
> 점수는 중립(50점)으로 처리합니다. 결과의 `reasons` 항목을 항상 같이 확인하세요.

## ⚙️ 처음 시작하는 방법

### 1. 패키지 설치
```bash
pip install -r requirements.txt
```

### 2. API 키 설정
한국투자증권 홈페이지에서 **Open API** 키 발급 후 `.env` 파일에 입력:
```bash
APP_KEY=여기에_앱키_입력
APP_SECRET=여기에_시크릿_입력
CANO=계좌번호8자리
ACNT_PRDT_CD=01
```
> 조회 전용이라도 KIS API 는 로그인(토큰 발급)이 필요해서 계좌 연동은 그대로 필요합니다.
> 매수/매도 권한은 쓰지 않으니 안심하세요 — 이 프로그램에는 주문 코드가 아예 없습니다.
> 해외주식 조회 권한도 계좌에 별도 신청이 필요할 수 있습니다 (KIS 홈페이지에서 확인).

### 3. 실행
```bash
python main.py                # 국내 시가총액 상위 유니버스(약 300~500종목) 스캔
python main.py --market us    # 미국(나스닥·뉴욕·아멕스 상위 100개씩) 스캔
python main.py --market all   # 국내 + 미국 모두 스캔
python main.py --quick        # 예전처럼 고정 66종목만 빠르게 스캔 (테스트용)
python main.py --top 10       # 상위 10개만 출력
python main.py --show-all     # 필터 통과 종목 전부 출력
```

> ⏱️ 전체 유니버스 스캔은 종목 수가 많아 국내는 5~10분, 미국은 2~3분 정도 걸릴 수
> 있습니다. 빠르게 테스트하려면 `--quick` 을 사용하세요.

### 4. 종목 목록 바꾸기 (--quick 모드)
`config.py` 의 `LARGE_CAP_SYMBOLS` / `LOW_PRICE_SYMBOLS` / `SECTOR_SYMBOLS` 에
종목 코드를 추가/삭제하면 `--quick` 실행부터 반영됩니다. 기본(전체 유니버스)
실행은 `full_universe.py` 의 가격대 구간(`KR_PRICE_BANDS`)이나 미국 거래소
목록(`US_EXCHANGES`)을 수정해서 범위를 조정합니다.

### 5. 기준값 조정하기
`config.py` 의 `SCREENER` 클래스 숫자를 바꾸면 "얼마나 엄격하게 걸러낼지"
바로 조정됩니다. 예: `PER_MAX = 10.0` 으로 낮추면 더 저평가된 종목만 남습니다.
(국내/미국 공통 기준값을 사용합니다.)

## ⚠️ 주의사항

1. **이 프로그램은 투자 조언이 아닙니다** — 점수가 높다고 반드시 좋은 투자처는 아닙니다.
2. **재무제표는 과거 데이터입니다** — 분기 재무제표는 발표 시점 기준이라 현재 상황과 다를 수 있습니다.
3. **미국 주식은 데이터가 더 제한적입니다** — 부채비율·성장률이 없고, ROE 는 근사치입니다.
4. **전체 유니버스 스캔은 시간이 걸립니다** — 국내 300~500종목 기준 5~10분, 미국 300종목 기준 2~3분 내외.
5. **API 키 보안** — `.env` 파일을 절대 공유하지 마세요.
6. **매매 기능 없음** — 이 프로그램으로는 주식을 사고팔 수 없습니다. 실제 매매는 증권사 앱/HTS 를 이용하세요.
